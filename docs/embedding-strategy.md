# Embedding Strategy

> Status: ✅ Implemented

## Overview

The AI Call Center RAG pipeline uses a locally deployed embedding model to convert normalized transcript chunks into vector representations for the RAG ingestion pipeline.

## Embedding Model

### Model

BGE-M3

### Deployment

BGE-M3 is deployed locally on the RAG infrastructure and is used for embedding generation without relying on external embedding APIs.

## Input

The embedding stage receives cleaned, normalized, and chunked transcript content generated by the speech-to-text pipeline.

## Processing Flow

Audio
↓
Speech-to-Text
↓
Text Cleaning & Normalization
↓
Chunking
↓
BGE-M3
↓
Vector Representation
↓
RAG Dataset

## Design Goals

- Local inference
- No dependency on external embedding APIs
- Integration with the existing local RAG infrastructure
- Consistent vector generation for the ingestion pipeline

## Current Status

The local BGE-M3 embedding model is operational and is used as part of the RAG ingestion workflow.

After successful embedding, the processed chunks are passed to the RAG dataset automatically.
